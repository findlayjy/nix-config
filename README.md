# Nix/Home Manager setup

Steps to get my home environment feeling familiar using Nix and Home Manager on another OS (e.g. Pop!\_OS).

## 1. Install the OS via the installer

Set up timezone, keyboard format, username (`jamief`), etc.

Set the hostname according to the profiles in `home.nix`:

``` bash
sudo hostnamectl set-hostname <host-name>     # replace <host-name> with e.g. "pc" on the PC
```

## 2. Set up git identity

```bash
git config --global user.name "Jamie Findlay"
git config --global user.email "jy.findlay@gmail.com"
```

## 3. Generate SSH key and add to GitHub

```bash
ssh-keygen -t ed25519 -C "jy.findlay@gmail.com"
cat ~/.ssh/id_ed25519.pub
```

Copy the output, add it at GitHub → Settings → SSH and GPG keys → New SSH key.

Test:

```bash
ssh -T git@github.com
```

## 4. Clone the config repos

```bash
git clone git@github.com:findlayjy/nix-config.git ~/nix-config
git clone git@github.com:findlayjy/.dotfiles.git ~/.dotfiles
```

## 5. Install Nix

```bash
curl --proto '=https' --tlsv1.2 -L https://nixos.org/nix/install | sh -s -- --daemon
```

## 6. Enable experimental features to use flakes

```bash
mkdir -p ~/.config/nix
echo "experimental-features = nix-command flakes" >> ~/.config/nix/nix.conf
```

## 7. Run Home Manager for the first time via its own flake

```bash
nix run home-manager/master -- switch --flake ~/nix-config#jamief
```

## Later rebuilds use a simpler syntax 

```bash
home-manager switch --flake ~/nix-config#jamief
```

## After: install Doom emacs

```bash
git clone git@github.com:findlayjy/doom.git ~/.config/doom
git clone --depth 1 https://github.com/doomemacs/core ~/.config/emacs
~/.config/emacs/bin/doom install
~/.config/emancs/bin/doom sync
```

## Note on COSMIC setup

The COSMIC config gets autogenerated live, and trying to overwrite it while COSMIC is running can lead to issues. To install the config while COSMIC is running, you have to drop into a TTY:

- `Ctrl`+`Alt`+`F2`, or, in the shell
```bash
sudo chvt 2
```

Once in the TTY, stop COSMIC
```bash
systemctl --user stop cosmic-session.target

```
Then `rm` the existing config and replace it:
```bash
rm -rf ~/.config/cosmic && ln -s ~/.dotfiles/.config/cosmic ~/.config/cosmic
```

To get back to the graphical session:
```bash
sudo chvt 1
```
